# Updating your existing GitHub repository

Repository: https://github.com/lnduongg/you-hear-that-portfolio

1. Extract the supplied ZIP to your computer.
2. Open the repository main page (not only its `/media` subfolder).
3. Choose **Add file → Upload files**.
4. Drag **the contents of `YouHearThat_Portfolio`** into the upload panel, keeping the `docs/` and `media/` directory layout. Do not create an extra `YouHearThat_Portfolio` folder inside the repository.
5. GitHub detects matching files (`README.md`, docs) and will show them as updates. Verify image paths like `media/tower-gameplay.png` before committing.
6. Choose **Commit changes** and refresh the repository home page. Check that images render and links work.

Alternative for fewer uploads: use GitHub Desktop to clone the repo, copy in the entire contents of the extracted folder, then Commit and Push.

The new ZIP is a *complete replacement snapshot* of the portfolio structure (not merely the `media` folder). Please do not upload the `.zip` itself into the repository.
