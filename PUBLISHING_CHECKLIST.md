# Publish This Portfolio on GitHub

## Prepare the Repository

1. On GitHub, create a public repository named `you-hear-that-portfolio` (or a name you prefer).
2. Upload `README.md`, `docs/`, and `media/` from this folder. Do **not** upload copyrighted third-party assets or a full Unity project unless you have checked the licenses.
3. In GitHub repository settings, add description: `Unity/C# psychological horror game — CCTV surveillance, Utility AI and Ink-driven narrative.`
4. Add topics: `unity`, `csharp`, `game-development`, `game-ai`, `ink`, `portfolio`.
5. Pin the repository on your GitHub profile.
